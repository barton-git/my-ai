# Amy-Trigger

为四年级学生 Amy 生成按时间排列、可直接照着执行的回家后计划表。使用中文和24小时制；当次用户要求优先于下列默认值。

## 默认设置

| 项目 | 默认值 |
|---|---|
| 作业照片目录 | 当前工作目录下的 `homework/` |
| 回家后开始时间 | 18:00 |
| 第一项 | 练琴25分钟 |
| 第二项 | 吃饭15分钟 |
| 各科作业 | 每个科目合计20分钟，包含本科所有子任务 |
| 休息 | 连续脑力劳动累计40分钟后安排10～15分钟，默认15分钟 |
| 固定课程 | 21:00开始口语课，持续30分钟 |
| 提前完成 | 前序任务全部完成后，口语课前剩余时间自由安排 |

用户指定其他目录时使用指定目录。相对路径以当前任务的工作目录为基准，不以 skill 安装目录为基准；不要依赖某台设备上的用户名或绝对路径。目录不存在时说明预期位置，并请用户提供照片所在目录或直接附图。

## 读取与识别

1. 每次执行重新列出照片文件，支持 JPG、JPEG、PNG、HEIC、WEBP 等可读取图片，忽略隐藏文件和非图片。按文件修改时间选最新一张；并列时按文件名排序并说明选用文件。用户指定某张照片或多张照片时遵从指定范围。
2. 实际打开图片，用视觉 OCR 或可用 OCR 工具识别作业；小字或模糊处可放大、裁切复核。不要沿用上一次的识别结果充当本次结果。
3. 逐科提取所有任务，包括订正、复习、背诵、口头任务、练习单，以及“学校通知／备忘”等区域中的学科作业。保留页码、课次、单元和题号；多张图片中的重复任务合并。
4. 《知》、知能、知训，以及同一作业本的手写简称，统一展开为对应科目的《知识与能力训练》。不把不同科目的作业本合并。
5. 看不清的字、页码或序号明确标为“待核对”，不要根据教材常识补写。局部不确定不妨碍先生成计划；图片不可读或目录无图片时说明实际情况并索取必要输入，不虚构作业。
6. 照片里的勾号、开始时间、完成时间保留为原始记录，不据此擅自删除任务或替换计划时间。用户明确哪些已完成时，再调整待做项目。
7. 简要注明本次照片文件名。照片日期不明确时称“本次计划／测试计划”，不要把文件上传或修改日期当成作业日期。

## 排时间

- 从18:00开始，依次安排练琴25分钟、晚餐15分钟，然后安排照片中识别出的各科作业。默认沿用照片中的科目顺序，备忘栏的额外科目接在后面。
- 每个科目整科分配20分钟，而非每道题或每条作业20分钟。表格内容栏列全本科任务；同科任务多时仍按20分钟估算，并说明超时可占用后续自由时间。
- 连续脑力劳动达到40分钟且后续还有学习时插入休息，默认15分钟。练琴也计入脑力劳动，随后的15分钟晚餐作为中断；饭后重新累计。完成全部作业后直接进入自由安排，不再额外插入重复休息。
- 口语课固定为21:00–21:30。前序任务全部完成后，到21:00之间的时间标为自由安排；只有实际完成才可自由活动。
- 如果任务无法在21:00前排完，明确标出冲突与剩余作业。时间表先排到21:00，保留固定口语课，列出课后续做的预计时段；必要时将20分钟科目时段拆开，保留该科总时长。不要挤掉休息、默默延后课程或生成重叠时间。
- 检查每行起止时间、时长、衔接、全部科目是否覆盖，以及固定课程是否准时。

## 输出

用一张按时间升序的 Markdown 表格呈现，列为：`时间 | 时长 | 安排 | 具体内容`。包含练琴、吃饭、各科作业、休息、自由安排（有剩余时间时）和口语课。表格前简要说明照片来源和科目数；表格后仅列待核对内容、时间冲突或必要的估时说明。默认直接在聊天中输出；用户要求文件时再保存相应文件。

排程核对示例（仅用于验证时间，不是固定的每日作业）：识别出语文、数学、英语、科学4科时，应为18:00练琴、18:25晚餐、18:40语文、19:00数学、19:20休息、19:35英语、19:55科学、20:15–21:00自由安排、21:00–21:30口语课。

## 后续迭代

用户要求“固化”“以后都这样”“更新 Amy-Trigger”时，读取并更新实际安装的本 skill，只改相关规则，保留其他约定，并递增 `metadata.version`。单次更改只作用于当次计划；不要自动把某天的作业内容变成长期默认任务。无需保存儿童照片到 skill 内。更新后复核排程示例是否仍与规则一致，并运行可用的 skill 校验工具。
